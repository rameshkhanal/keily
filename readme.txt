== Description ==

Keily is a Full Site Editing theme. It lets you edit headers, footers, sidebars, templates and individual page elements in the Site Editor, without writing code. It includes block patterns, block styles and two style variations.

== Changelog ==
= 1.0.2 - August 24 2026 =
* Fixed: only one of ten block styles was registered.
* Fixed: pattern strings used esc_html() instead of esc_html__(), so they were not translatable.
* Fixed: no root font family set in theme.json.
* Fixed: Contact pattern used a hardcoded Contact Form 7 form ID.
* Fixed: WorkSans italic and weight 300 font faces.
* Fixed: invalid font-weight range on the Montserrat variable fonts.
* Fixed: Montserrat had no fallback font stack.
* Fixed: link and hover colours, and button label colour in the Blues style, for contrast.
* Fixed: links kept their underline on hover.
* Fixed: typos in pattern text and a wrong support email address.
* Fixed: front page had nine H1 elements.
* Fixed: decorative counters and labels in patterns were marked up as headings.
* Fixed: heading hierarchy in the Experience and Project patterns.
* Fixed: stylesheet version read from the wrong theme under a child theme.
* Changed: removed add_theme_support() for experimental-link-color and custom-units.
* Changed: corrected the readme headers, tags and copyright section.
* Added: languages/keily.pot
* Tested with WP 7.1

= 1.0.1 August 14 2023 =
* Fixed reviewer issues.
